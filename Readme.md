# AI/ML College Projects

Academic projects completed during my undergraduate studies, covering foundational machine learning concepts. Each project includes a Jupyter notebook with documented analysis and results.

> **Note:** These are college-era projects, not production code. They reflect learning milestones rather than current professional work.

---

## Projects

### [Network Intrusion Detection System](./Network_Intrusion_Detection_System/)

Intrusion Detection System (IDS) built using a deep neural network with **self-supervised contrastive learning** — eliminating the need for labeled training data.

- Classifies network traffic as normal or malicious using a fully connected ANN
- Applies contrastive learning to learn representations from unlabeled data
- Published in [IJSRD Vol. 11, Issue 3](./Network_Intrusion_Detection_System/IJSRDV11I30128.pdf)

`Python` `TensorFlow` `Pandas` `NumPy` `Scikit-learn`

---

### [Linear Regression — Climate Change](./Linear-Regression/Climate-Change/)

Analysis of climate data (May 1985 – Dec 2005) to model the relationship between year and global temperature rise using linear regression.

- Data sourced from Kaggle; preprocessed with Pandas
- Visualized trends using Matplotlib
- Implemented linear regression from scratch and via Scikit-learn

`Python` `Pandas` `NumPy` `Matplotlib` `Scikit-learn`
